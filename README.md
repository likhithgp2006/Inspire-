# 🌟 Inspire

A web platform built to inspire and connect.

## 🚀 Live Demo

👉 [https://inspire-six-nu.vercel.app/](https://inspire-six-nu.vercel.app/)

## 📦 Project Structure

- `index.html` — Main frontend
- `admin.html` — Admin panel
- `demo-site.html` — Demo/preview site
- `inspire_backend/` — Django REST API backend
- `google_sheets_sync_script.gs` — Google Sheets sync script
- `render.yaml` — Render deployment config

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Django (Python)
- **Deployment**: Vercel (frontend) · Render (backend)
